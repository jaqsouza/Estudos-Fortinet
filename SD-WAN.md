# SD-WAN / Software Defined  

O SD-WAN é como um profissional de transito, ele vê qual é o melhor caminho para os dados trafegarem.  

Leva em conta as condições de rede no momento, assim envia o pacote e direciona o trafego para o link que melhor atende os requisitos das aplicações e políticas pré definidas.  

Sem ele a internet seria lenta, travada e menos segura.
